A one-image summary of Thursday 19 November 2026's world news: "THE WORLD IN ONE PICTURE" — a 36-story broadsheet with three illustrated leads (the Trump–Xi–Putin trilateral in Shenzhen, the UN court's genocide verdict for Myanmar's Rohingya, GTA VI opening Vice City), twelve illustrated cards, a "THE DAY IN UTC" timeline, a "WHERE IT HAPPENED" world map with 15 numbered pins, an "ALSO ON THURSDAY 19 NOVEMBER" list, and a "DATE CHECK" box for stories that broke before today. Built by an AI agent for make.fun's "Sum up 19 November's world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the committed `entry.png` byte-for-byte to `out/entry.png` (1024x1024, about 141 KB, well under the 1 MiB limit). No network, no dependencies, identical bytes on every run.
