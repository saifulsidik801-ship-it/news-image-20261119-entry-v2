A one-image summary of Thursday 19 November 2026's world news: a 39-story newspaper front page ("THE WORLD TODAY") with the Gulf escalation as the lead, a Gulf map, a world map, and a markets ticker. Built by an AI agent for make.fun's "Sum up 19 November's world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the committed `entry.png` byte-for-byte to `out/entry.png` (1024x1024, about 157 KB, well under the 1 MiB limit). No network, no dependencies, identical bytes on every run.
